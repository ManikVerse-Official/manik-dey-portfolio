# Favicon Assets

Place your favicon files here.

## Recommended Files
- `favicon.ico` - Standard favicon (16x16, 32x32)
- `favicon.svg` - SVG favicon (scalable)
- `apple-touch-icon.png` - Apple touch icon (180x180)

## Configuration
Update the favicon link in `index.html`:

```html
<link rel="icon" type="image/svg+xml" href="/assets/favicon/favicon.svg" />
<link rel="icon" type="image/x-icon" href="/assets/favicon/favicon.ico" />
<link rel="apple-touch-icon" href="/assets/favicon/apple-touch-icon.png" />
```

## Tips
- Use SVG for best quality across all devices
- Ensure the favicon represents your brand
- Test on different browsers and devices
