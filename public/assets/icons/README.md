# Icons Assets

This folder is for additional custom icons if needed.

## Usage
Currently, the project uses Lucide React icons for most UI elements. This folder can be used for:
- Custom brand icons
- Specialized icons not available in Lucide
- Logo variations

## Configuration
Custom icons can be imported and used in components similarly to how project images are handled.

## Tips
- Use SVG format for best quality
- Ensure consistent styling with the overall design
- Keep file sizes optimized for performance
