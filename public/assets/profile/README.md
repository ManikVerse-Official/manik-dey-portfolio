# Profile Image

Place your professional profile photo here.

## Supported Formats
- JPG
- JPEG
- PNG
- SVG
- WebP

## File Name
The image should be named: `profile.jpg` (or your preferred format)

## Configuration
The profile image path is configured in `src/data/siteConfig.js`:

```javascript
profile: {
  image: "/assets/profile/profile.jpg",
  alt: "Professional profile photo"
}
```

## Tips
- Use a professional, high-quality photo
- Recommended size: 400x400px or larger
- Ensure good lighting and clear visibility
- The image will be displayed in a circular format in the Hero section
